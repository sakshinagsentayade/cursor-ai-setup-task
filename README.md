# AI Development Tools Setup

## Overview
This project documents the setup of AI-powered development tools in Cursor IDE, including Claude Code and Codex extensions, along with the GitHub workflow used to publish the repository.

## Tools I Installed

1. **Cursor IDE**
   - Downloaded and installed from https://cursor.com/
   - Used as the main code editor for the project

2. **Claude Code add-on**
   - Installed from Cursor Extensions by searching for "Claude Code"
   - Logged in after installation

3. **Codex add-on**
   - Installed from Cursor Extensions by searching for "Codex"
   - Logged in after installation

## Steps I Completed

1. Installed Cursor IDE.
2. Opened the Extensions panel in Cursor.
3. Searched for and installed the Claude Code add-on.
4. Searched for and installed the Codex add-on.
5. Created a public GitHub repository.
6. Opened the repository in Cursor.
7. Created this README.md file.
8. Committed and pushed the repository to GitHub.

## Issues I Ran Into and How I Solved Them

### Issue: Claude Code command not found
**Problem:** When I opened Claude Code in Cursor, I saw an error saying `command 'claude-vscode.editor.openLast' not found`.

**Solution:** I reloaded Cursor, uninstalled and reinstalled the Claude Code extension, updated Cursor, and then signed in again. After reinstalling, I opened a fresh Claude Code session instead of trying to restore the old one.

**Problem:**I was not able to log into Claude Code.

**Solution:** I uninstalled the extension which i have downloaded then i had to restart and then reinstall the Claude Code 

**problem**I created a file named: Sample_Cursor_File.py but the file it did not run.

**Solution** I had to install the extensions: python and Python Debugger then the file executed succesfully.
